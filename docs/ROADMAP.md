# Roadmap

The gallery is running today. Everything below marked planned requires implementation and evidence before it is advertised as supported.

| Stage | Status | Deliverable | Proof before completion |
| --- | --- | --- | --- |
| Offline gallery | Working | 28 views, two themes, touch/serial controls | Build, seven asset checks, flash/runtime observations and physical feedback |
| Upright blue smile eyes | Working | U U eyes in both individual blue/cyan smile views | Orientation regression, unchanged-frame hashes and inspected previews |
| Original face families | Planned | Reference-approved white, black and color faces | Provenance, intended eye orientation and real-size visual review |
| Event protocol | Planned | Bounded device states and offline simulator | Duplicate/stale-event, offline and reconnect tests |
| Live + Decisions | Planned, required | Spoken interaction and bounded action/reaction selection | Real session/decision events, measured timing and truthful playback state |
| Images | Planned, required | Generate/edit → preview → export → stage → activate | Real generated asset, transfer hash, display acknowledgment and interrupted-transfer test |
| Onboard audio | Planned | Microphone, speaker and bounded streaming | Exact board format, dropout/echo and interruption/mute measurements |
| Multi-Dotlet UI | Planned | Devices, profiles, activity and usage controls | Two physical devices, separate identities, revocation and conversation isolation |
| Cookbook candidate | Planned | Focused recipe, minimal bridge, tests and audible demo | Maintainer-reviewed scope and reproducible current-API implementation |

Useful extensions after the required slice include Responses tools, retrieval, explicit memory, Agents SDK/API orchestration, transcripts/translation and optional MCP/plugins. Each needs a user-visible purpose, an authorization boundary and its own verification.

A GitHub star count, a rendered face, a successful HTTP request or a model saying “done” is not proof of completed device work. Keep planned, built, locally tested and physically verified states distinct.
