# Gallery artwork

These PNGs are AI-assisted digital reconstructions inspired by OpenAI event sticker sheets, prepared for this independent hardware experiment. They are not official source files or exact authenticated reproductions.

- `atlas-black.png`: 24 tiles with black backgrounds; all knot logos are white.
- `atlas-light.png`: the approved earlier light-background theme, with both logo polarities.
- `devday-*-digital-v1.png`: reconstructed reference sheets used for the final four gallery views.
- `names.json`: the 28 frame labels, in display order.

The root MIT license does **not** cover these images, OpenAI logos or other third-party marks. Their inclusion is not a grant of trademark rights or a representation that HeySalad owns the underlying event designs. Use your own artwork when you need a permissively licensed art pack.

The software can render replacement atlases with the same dimensions and layout. See the main README for the export process.
